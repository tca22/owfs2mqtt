# Contributing

Bug reports, documentation improvements, tests, and focused code changes are
welcome.

## Development

Run the automated test suite with:

```bash
pytest -q
```

Please keep changes small and focused. Do not commit local deployment files,
credentials, real alias mappings, or site-specific configuration.

## Pull requests

Describe the problem, the change, and how it was tested. Functional changes
should include or update tests where practical.
